# AeroKinetic-1MW-Slotless-BLDC v2.0.0-HV — Release Notes

### 🚀 High-Voltage Upgrade Benchmarks ($5.0\text{ kV} / 200\text{ A}$)

* **Gravimetric Power Density:** **$18.52\text{ kW/kg}$** ($54\text{ kg}$ engine mass vs $88\text{ kg}$ in v1.0.0).
* **Feeder Cable Harness Weight:** Reduced from $42\text{ kg}$ down to **$9.5\text{ kg}$** ($77.4\%$ harness weight reduction).
* **Inverter Topology:** 5-Level Active Neutral-Point Clamped (ANPC) SiC bridge operating at $40\text{ kHz}$.
* **$dV/dt$ Transient Stress:** Slashed from $377.78\text{ kV/}\mu\text{s}$ to **$94.44\text{ kV/}\mu\text{s}$** ($75\%$ stress reduction).
* **Dielectric Materials:** Nano-$\text{Al}_2\text{O}_3$ polyimide insulation matrix with coaxial SWCNT ground shielding ($E_{\text{break}} = 320\text{ kV/mm}$).
* **Insulation Endurance Life:** Extended from $2,445\text{ hours}$ to **$48,176\text{ hours}$** ($2.41\times$ above the 20,000-hour commercial aviation threshold).
* **Kinetic Regeneration:** $10.84\%$ net mission energy recovery ($74.73\text{ kWh}$) with zero-current interlocked coil switching.

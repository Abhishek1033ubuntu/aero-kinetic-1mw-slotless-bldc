# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security flaw or timing vulnerability in the C control firmware routines or simulation models:

1. **Do not open a public issue.**
2. Send an email to the lead investigator: **Abhishek Singh** via [ORCID 0009-0004-6913-096X](https://orcid.org/0009-0004-6913-096X).
3. Include detailed steps to reproduce the vulnerability. You will receive an acknowledgment within 48 hours.
